# Product

## Register

product

## Users

Real estate investors evaluating potential rental properties. They want a fast, lender-grade DSCR number without running spreadsheets or waiting for their bank. They're in research mode — comparing several properties, moving quickly, and need trustworthy numbers they can act on.

## Product Purpose

DSCR Verdict gives investors an instant debt-service-coverage-ratio verdict for any US rental property. Enter property details or a listing URL, get a pass/caution/fail verdict with full itemized breakdown. The core value is speed + trust: one click instead of 20 minutes in Excel.

## Brand Personality

Confident, precise, trustworthy. The interface should feel like a professional financial tool — numbers carry authority, layout is clean but not sterile, everything serves the single goal of getting a reliable verdict fast.

## Anti-references

Not generic SaaS cream. Avoid the beige-on-white Intercom/Linear clone look that dominates B2B tools. This is a real estate financial tool — it should have its own character. Not consumer-real-estate (Zillow, Redfin) and not over-designed fintech (Robinhood).

## Design Principles

1. **The verdict is the hero.** Every screen leads to the DSCR number. Layout, hierarchy, and flow push toward that single output.
2. **Precision without friction.** Financial data needs accuracy and clarity, but the tool should feel fast. Don't make users hunt for inputs.
3. **Confidence through clarity.** Show the full itemized breakdown. An educated user trusts the result more when they can see exactly how it was calculated.
4. **Not another SaaS template.** Avoid the standard cream-canvas + floating cards look. Lean into a more grounded, professional visual language that suits a real estate financial tool.

## Accessibility & Inclusion

Standard best practices. Sufficient contrast, keyboard-navigable forms, focus indicators.
